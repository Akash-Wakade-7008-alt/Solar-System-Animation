## ⚙️ Local Setup

### Option 1: Clone the Repository

```bash
git clone https://github.com/Akash-Wakade-7008-alt/Solar-System-Animation.git

cd SOLAR_SYSTEM_ANIMATION

open index.html

```

### 📦 Option 2: Download ZIP

Download the project directly:
